О системе HelpDesk

HelpDesk — корпоративная система для управления заявками на техническое обслуживание, учёта комплектующих и оборудования. Она позволяет сотрудникам создавать заявки, отслеживать их статус, а системным администраторам — обрабатывать заявки, вести складской учёт и анализировать статистику.

Роли пользователей

  • Неавторизованный пользователь – имеет доступ к странице с инструкцией для ознакомления с работой сайта. Доступ к другим страницам ограничен.
  • Пользователь – создаёт, просматривает и редактирует свои заявки. Пользователь может удалить заявку, если она не перешла из статуса «Новая».
  • Системный администратор – видит все заявки, меняет статус любой заявки, управляет комплектующими.
  • Администратор – имеет доступ к админ-панели для управления дополнительными данными.

Авторизация и выход

Вход выполняется по номеру телефона и паролю. Кнопка «Выйти» находится в шапке сайта.

Работа с заявками

Для обычного пользователя

  • Просмотр своих заявок – на странице «Заявки» отображаются только ваши заявки.
  • Создание заявки – нажмите «Создать заявку», заполните описание и отправьте.
  • Просмотр деталей – кликните по любой заявке в списке.
  • Редактирование – при необходимости имеется возможность редактирования данных по ссылке «Изменить заявку».
  • Удаление – доступно только для заявок со статусом «Новая» (ссылка «Удалить заявку»).

Для системного администратора

  • Просмотр всех заявок – видны заявки всех сотрудников.
  • Изменение статуса чужой заявки – на странице заявки появляются кнопки «Принять заявку» или «Закрыть заявку».
  • Редактирование текста – доступно только для заявок, чьим владельцем вы являетесь.
  • Удаление – только владелец может удалить свою заявку (статус «Новая»).
  • Добавление решения – добавление решения проблемы к заявкам. Добавить решение можно в любое время. Решения видят только системные администраторы

Управление комплектующими

Доступно только системному администратору и администратору.

  • Просмотр всех комплектующих с количеством на складе.
  • Поиск по модели или типу (регистр не важен).
  • Списание со склада – укажите количество и нажмите «Убрать из склада».

Поиск и фильтрация заявок

На странице «Заявки» можно искать по тексту проблемы или фамилии сотрудника, а также фильтровать по статусу. Аналогичные поиск и фильтрация работает на странице «Комплектующие»

Просмотр статистики

Для системного администратора

  • Просмотр своих показателей – количество принятых и завершенных заявок.
  • Просмотр топ отделов – топ 5 отделов, в которых были приняты заявки.

Для администратора

  • Просмотр показателей по заявкам – общее количество заявок, число в статусе "Новые", "В работе", "Завершённые".
  • Просмотр показателей по комплектующим – общее количество на складе и число комплектующих с остатком меньше 5.
  • Динамика создания заявок за последние 30 дней – график, показывющий сколько заявок было создано в определенный день за последние 30 дней.
  • Соотношение заявок по статусам – круговая диаграмма, показывающий процент соотношения заявок по статусу.
  • Принятые vs Завершенные заявки по дням за последние 30 дней – столбчатая диаграмма, показывающая общее количество принятых и завершенных заявок в определенный день за последние 30 дней.
  • Просмотр топ отделов по заявкам – топ 5 отделов с наибольшим количеством созданных заявок.
  • Просмотр топ сисадминов по принятым заявкам – топ 5 сисадминов с набольшим количеством принятых заявок.
  • Просмотр топ сисадминов по завершенным заявкам – топ 5 сисадминов с набольшим количеством завершенных заявок.
  • Просмотр последниз списаний комплектующих – таблица, в которой указаны модель комплектующего, ФИО системного администратора, количество и дата списания.
  • Экспорт заявок и транзакций – кнопки, по которым можно экспортировать данные по заявкам и по списанию комплектющих в формате CSV.

Работа с админ-панелью

Доступно только администратору.

  • Просмотр всех данных: комплектующие, оборудование, заявки, пользователи, отделы, кабинеты.
  • Редактирование и удаление любых записей.
  • Создание новых пользователей и назначение ролей. При создании администратора дополнительно ограничить его действия с помощью групп пользователей
  • Создание групп пользователей и настройка прав.

Важные ограничения

  • Заявку нельзя удалять, если она переведена в статус «В работе» или «Завершена».
  • Обычный пользователь не видит чужие заявки.
  • Неавторизованный пользователь видит только страницу входа.
  • Работа с админ-панелью предоставлена только администраторам сайта.
